# Cloud Compliance Risk Assessment – NIST CSF 2.0

## Project Overview
This portfolio project presents a simulated cloud compliance risk assessment aligned with the NIST Cybersecurity Framework (CSF) 2.0. It demonstrates practical skills in identifying, evaluating, documenting, and prioritizing cloud security and compliance risks.

## Key Deliverables
- Cloud risk register covering 12 identified risks
- Risk scoring based on likelihood and impact
- NIST CSF 2.0 control mapping
- Evidence tracking and compliance documentation
- Dashboard with prioritized findings
- Recommended remediation actions and ownership

## Key Findings
- 3 Critical risks
- 8 High risks
- 1 Medium risk

Priority remediation areas include restricting public cloud storage access, enabling multi-factor authentication for administrator accounts, applying least-privilege access, and collecting evidence of completed remediation.

## Tools and Frameworks
- Microsoft Excel
- NIST Cybersecurity Framework 2.0
- Risk assessment and evidence tracking
